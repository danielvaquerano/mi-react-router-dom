# 🎵 Kodigo Music

Una aplicación web de música construida con React y Vite que permite reproducir canciones locales.

## Características

- Interfaz moderna con tema oscuro
- Grid de canciones responsive
- Reproductor con controles de play/pause
- Diseño flotante con efectos visuales
- Barra de progreso para cada canción

## Tecnologías utilizadas

- React 18
- Vite
- CSS3 con Grid y Flexbox
- HTML5 Audio API
